# コース・UIレビュー（2026-09-12）

## 確認範囲

標準7コースの選択・レース起動・開始地点の描画、ホーム・ソロ選択の画面、既存の入力・ポーズ・リスタートをDocker内のChromiumで確認。画面寸法は1280×800、844×390、390×844、667×375。全コースの完走、実機のジャイロ、複数端末での通信、GPU性能比較は対象外。

## 評価と今回の改善

- ホーム：紺を基調にソロ・マルチ・エディタを色分けした構成は良好。主要操作が識別できる。縦画面の補助ボタンは文字単位で折り返されていたため、ボタン単位の折り返しへ変更。
- コース選択：従来は前後矢印だけで、離れたコースへ何度も送る必要があった。標準・保存コース共通の一覧を追加。閲覧中のコースと確定済みコースは引き続き分離する。
- 比較情報：周回数・背景説明だけでは走行条件が分かりづらかった。実際の路面曲線から1周の概算距離と高低差を計算し、ジャンプ台数とともに表示。難易度の断定はせず、比較可能な値を使う。
- 俯瞰図：スタート位置だけでは進行方向が分からなかったため、曲線の接線方向に白い矢印を3個追加。SVGの背景線を角丸の図の範囲へクリップ。
- コース：草原・峡谷・宇宙・天空・都会・極寒地・お菓子のテーマは色と背景で区別できる。ただし俯瞰形状は全体的に周回オーバル寄りで、走行上の個性はさらに伸ばせる。

## 次に優先したい改善案

1. **暗いコースの路肩表示**：宇宙・都会ではタイヤ壁や車体が背景に沈みやすい。路肩の発光色と反射マーカーを小さく調整し、同じ地点・同じ露出で比較する。判定や幅は変更しない。
2. **コース別の攻略案内**：ジャンプ台・壁の切れ目・急カーブを俯瞰図に表示し、初見のコースアウトを減らす。装飾を増やす前に進路の読みやすさを優先。
3. **自己ベストとラップ差分**：同じコース・車体・ルールの記録で比較し、走り直す目的を作る。CPU学習やスキル条件が違う記録は混同しない。
4. **コース形状の差別化**：初心者用の広いオーバルを残し、別コースにS字・ヘアピン等を追加する。CPUの脱落率、壁への接触回数、完走率を変更前後で測る必要があり、今回のUI変更には含めない。

## 検証

`tests/course_review.cjs` は7コース起動、一覧選択、確定状態の保持、方向矢印、各画面寸法での操作到達、カスタムコースの高低差を検証する。縦画面ではスクロールによる到達を許容する。画像は既定でコンテナの `/tmp`、`REVIEW_ARTIFACT_DIR` があればそのディレクトリへ出力する。
