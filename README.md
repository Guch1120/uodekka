# HTML5 3D カートレーシング

スマホのジャイロ傾き操作、カスタマイズ可能な画面ボタン配置、マリオカート風アイテム、3コース、WebSocketゲームサーバー経由のマルチプレイ機能を備えたHTML5 3Dレースゲームです。

## 操作方法

起動時は「UO:De Car」のタイトル画像が表示されます。画面のどこかをタッチ（PCではクリック、または Tab で選択して Enter / Space）すると、部屋作成・参加・ひとりで遊ぶロビーへ進みます。画像は縦横比を保って画面内に収まり、余白部分もタッチできます。

### スマートフォン
- **ステアリング (ハンドル操作)**:
  - **ジャイロモード (デフォルト)**: スマホ本体を左右に傾けることでステアリング操作。
    ※iOS/一部Androidでは設定画面または初期画面から「ジャイロを有効化」ボタンを押して許可します。
  - **バーチャルスティックモード**: 設定から切り替えると画面左側にアナログスティックが出現し、指のスライドで旋回できます。
- **アクセル**: 画面右側をタップ、または右下の「アクセル」ボタンを長押し。
- **ブレーキ/バック**: 「ブレーキ」ボタン。
- **ドリフト**: 「ドリフト」ボタンを押しながら旋回。コーナーを曲がり続けるとミニターボ発動！
- **アイテム使用**: 画面右上のアイテムスロット、または「アイテム発動」ボタンをタップ。

### PC (キーボード)
- **ステアリング**: `A` / `D` または `←` / `→`
- **アクセル**: `W` または `↑`
- **ブレーキ/バック**: `S` または `↓`
- **ドリフト**: `Shift` または `Space`
- **アイテム発動**: `E` / `Q` / `Enter`

## 設定・UIカスタマイズ機能
1. 右上の歯車アイコン（⚙）をタップすると設定画面が開きます。
2. **ジャイロ / スティックの切替**、**ジャイロ感度**の変更が可能です。
3. **「レイアウト変更モード開始」** をタップすると、画面上のボタン（アクセル、ブレーキ、アイテム、ドリフト、スティック）がハイライトされ、**指でドラッグして好きな画面位置へ自由に配置**できます。
4. 配置はブラウザの `localStorage` に自動保存され、次回プレイ時も保持されます。

## WebSocketマルチプレイ
- **部屋をつくる (ホスト)**:
  - コースと機体を選んで「部屋を作成してID発行」をクリック。
  - 発行されたルームID、または画面に表示される**招待QRコード**・URLを対戦相手に共有します。
- **部屋に入る (ゲスト)**:
  - ホストのQRコードをスマホのカメラで読み取るか、招待URLを開くだけで自動的にルームに参加できます。
  - Cloudflare Workers上のWebSocketゲームサーバーを経由して通信します。端末間の直接接続やTURN設定は不要です。
- **ひとりで遊ぶ (CPU対戦)**:
  - 11台の個性豊かなCPUカートと一緒に、合計12台の迫力あるレースを楽しめます。
  - CPUはプレイヤーの実際の運転（走行ライン、進入速度、ドリフト、アイテム操作）を走行ごとに学習し、賢く速く成長していきます。
- **マルチプレイ (最大12人・CPU自動補充)**:
  - 参加人数が12人に満たない場合、不足枠はCPUが自動参戦し、常に白熱の12人レースを楽しめます。

## 起動方法
公開前は `npm run build` を実行します。競合マーカー、JavaScript（HTML内を含む）の構文、相対モジュール参照、ソースと `.vercel/output/static` の不一致があれば失敗します。成功した場合のみ `dist` を作成します。Vercelの通常ビルドにも同じチェックを設定しています。`--prebuilt` による直接公開はビルドチェックを迂回するため使用しないでください。

起動検証は `node tests/startup.cjs`（Playwrightが必要）です。既存環境は `PLAYWRIGHT_MODULE` / `CHROME_PATH` で指定できます。正常なホーム・ソロ開始と、取得失敗・構文エラー・初期化エラー時の診断表示を検証します。実機Safari/Androidと公開後の確認は別途必要です。

静的ファイルとして動作するため、ローカルWebサーバー（例: `python3 -m http.server 8000` または `npx serve`）を起動し、ブラウザで `http://localhost:8000` にアクセスしてください。

## ホーム・ルームUI

タイトルをタッチするとホームが開きます。プレイヤー名を入力し、左右の矢印で車体を選択してください。ソロではコース俯瞰図を切り替え、「コース決定」または「ランダム決定」で確定後にレースを開始します。車体パラメータのバーは実際の速度・加速・重さに対応します。

マルチではホストが3〜32文字の半角英数字・ハイフンのルームIDを設定し、ゲストは同じIDまたは招待URLから参加します。メンバー名と選択コースは全員に同期され、コース決定・開始はホスト専用です。マルチは全員が持つ標準3コースから選ばれます。カスタムコースはソロ画面とコースエディタで利用できます。ルームは最大8人で、ホストの退出時はゲストもホームへ戻ります。

通信プロトコルの公開検証は `wrangler deploy --dry-run` と、Cloudflare Workerの公開URLを使った実機接続で行います。静的ファイルはVercel、WebSocketとDurable ObjectはCloudflare Workersへデプロイします。現在の配信対象 `.vercel/output/static` にも変更した配信ファイルを同期してから commit・push してください。Production URL: https://takufcbarcamessi10-8840.vercel.app/

### 開始前UIの拡張

車体データは `frontend/vehicles/vehicles.js` に集約しています。`image` に画像URLを設定すると3Dプレビューを差し替えられます（未指定・読み込み失敗時は3D表示）。`category` と `description` も同じデータから表示します。性能はゲーム本体と共通の `topSpeed / acceleration / weight` を参照します。

標準コースの `previewImage` に画像URLを設定すると俯瞰図を差し替えられます。未指定・読み込み失敗時はコース座標から生成します。閲覧コースを変更しても確定済みコースは保持され、画面には実際にレースで使用する確定コース名を表示します。開始コールバックには `playerName / vehicleKey / courseId / mode / isHost` を渡します。

## 高さ付きコースメーカー

ホームの「コースを作る」から、3Dプレビュー・上から編集・高さを編集を切り替えられます。3Dはドラッグで回転、ホイールまたはピンチで拡大縮小できます。「全体を表示」で表示範囲を戻します。

高さ編集の横軸はスタートからの平面上の走行距離、縦軸は高さ（0〜120m）です。頂点を上下にドラッグするか、頂点番号を選んで高さを数値入力します。ゴールは頂点1と同一で、高さは連動します。「元に戻す」は最大50操作、「すべて平らにする」は全頂点を0mに戻します。急勾配はグラフ上に表示します。

「保存」でブラウザに保存し、「コース設定・保存コース」から再編集できます。「テスト走行」またはソロのコース一覧で、選択した車体を使ってCPUと走れます。保存に失敗した場合は開始せず、画面に理由を表示します。マルチでのカスタムコース共有、立体交差の上下判定、ジャンプは今回の対象外です。

内部ではX/Zを平面、Yを高さに使用し、共通の `course_curve.js` でエディタ・道路・俯瞰図の形状を生成します。高さの補間は平面形状を変えず、頂点間で高さが行き過ぎず、周回の接続が滑らかになる方式です。高さ未設定の古い保存データは0mとして読み込めます。

## 通信の設定・デプロイ

接続段階の表示、自動再接続、ルーム情報の再取得、診断コピーを追加しています。WebSocketサーバーの設定方法と検証手順は [マルチプレイ通信](docs/multiplayer-network.md) を参照してください。通信サーバーは `worker/index.js` のCloudflare Durable Objectで動作します。

ローカルWorkerは `pnpm dev:worker` で起動できます。公開済みの接続先は `wss://uodekka-multiplayer.kurehiro1009.workers.dev/ws` です。Workerを更新する場合はCloudflareへログインしたあと `pnpm deploy:worker` を実行し、URLを変更したときだけ `index.html` の `window.MULTIPLAYER_SERVER_URL` も更新してください。
